1Standard RBC

Agent solves

\(\displaystyle \max \sum_{t = 1}^{\infty} \beta^t \mathbb{E}_t \frac{c_t^{1 - \gamma}}{1 - \gamma}, \forall t = 1 \ldots \infty\) (1)

subject to

\(\displaystyle c_t + k_{t + 1} = A_t k_t^{\alpha} + (1 - \delta) k_t\)

The first-order conditions are

\(\displaystyle \begin{array}{rl} \beta^t c_t^{- \gamma} = & \lambda_t\\ \lambda_t = & \mathbb{E}_t \lambda_{t + 1} (A_{t + 1} k_{t + 1}^{\alpha - 1} + 1 - \delta) \end{array}\)

So our Euler equation is

\(\displaystyle \frac{1}{c_t^{\gamma}} =\mathbb{E}_t \frac{1}{c_{t + 1}^{\gamma}} (A_{t + 1} k_{t + 1}^{\alpha - 1} + 1 - \delta)\) (2)

2RBC with labor

Agent solves

\(\displaystyle \max \sum_{t = 1}^{\infty} \beta^t \mathbb{E}_t \frac{c_t^{1 - \gamma}}{1 - \gamma} - \chi \cdot \frac{n_t^{1 + \frac{1}{\nu}}}{1 + \frac{1}{\nu}}\) (3)

subject to

\(\displaystyle c_t + k_{t + 1} = A_t k_t^{\alpha} n_{t }^{1 - \alpha} + (1 - \delta) k_t\)

So the first-order conditions are

\(\displaystyle \begin{array}{rl} \beta^t c_t^{- \gamma} = & \lambda_t\\ \chi n_t^{\frac{1}{\nu}} = & \lambda_t (1 - \alpha) A_t k_t^{\alpha} n_t^{- \alpha}\\ \lambda_t = & \mathbb{E}_t \lambda_{t + 1} \left( {A_{t + 1}} k_{t + 1}^{\alpha - 1} n_t^{\alpha} + 1 - \delta \right) \end{array}\)

So the 2 optimal conditions are

\(\displaystyle \begin{array}{rl} n_t^{\frac{1}{\nu}} = & \frac{1}{\chi} \cdot c_t^{- \gamma} (1 - \alpha) A_t k_t^{\alpha} n_t^{- \alpha}\\ c_t^{- \gamma} = & \mathbb{E}_t c_{t + 1}^{- \gamma} \left( {A_{t + 1}} k_{t + 1}^{\alpha - 1} n_{t + 1}^{\alpha - 1} + 1 - \delta \right) \end{array}\)

Since the intratemporal condition is uniquely pin down by the choice of \(c_t\),

\(\displaystyle n_t^{\frac{1}{\gamma} + \alpha} = \frac{1}{\chi} \cdot c_t^{- \gamma} (1 - \alpha) A_t k_t^{\alpha}\)

We can write the Euler equation solely in \(c_t\)

\(\displaystyle \begin{array}{ll} c_t^{- \gamma} = & \mathbb{E}_t c_{t + 1}^{- \gamma} \left[ {A_{t + 1}} k_{t + 1}^{\alpha - 1} \left( \frac{1}{\chi} \cdot c_{t + 1}^{- \gamma} (1 - \alpha) A_{t + 1} k_{t + 1}^{\alpha} \right) ^{\alpha - 1 \left( \frac{1}{\gamma} + \alpha \right)} + 1 - \delta \right] \end{array}\) (4)
